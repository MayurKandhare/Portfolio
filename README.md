# Mayur Kandhare | Data Analyst Portfolio

A personal portfolio website for **Mayur Kandhare**, a final-year B.Tech student (Computer Science and Engineering, Data Science) and aspiring Data Analyst. It shows my background, skills and Power BI dashboard projects in one clean, responsive page.

**Live site:** https://mayurkandhare.github.io/Portfolio/

## What's inside

- **Summary and Experience:** a short introduction and what I'm looking for (Data Analyst internships and entry-level roles)
- **Projects:** three Power BI dashboards
  - Employee Attrition Analysis (HR Analytics)
  - Marketing Campaign Success Analysis (Marketing Analytics)
  - E-Commerce Sales Dashboard (Sales Analytics)
- **Skills:** SQL, Python, Pandas, NumPy, Microsoft Excel, Power BI, DAX, data cleaning, EDA, KPI analysis and data visualization
- **Education and Certifications**
- **Contact:** email, mobile number, location, LinkedIn and GitHub

## Built with

- HTML, CSS and a little JavaScript (no frameworks)
- Google Fonts (Nunito)
- Responsive design that works on phones, tablets and computers

## Project structure

```
portfolio/
├── index.html      # page structure and content
├── style.css       # all styling (light and dark themes)
├── script.js       # lightbox, filters, counters, copy buttons, theme toggle
├── theme.js        # applies saved light/dark choice on load
├── Mayur_Kandhare_Data_Analyst_Resume.pdf
├── images/         # profile photo and dashboard screenshots
└── README.md
```

## Run it locally

1. Download or clone this repository.
2. Open `index.html` in any browser. Keep the `images` folder next to it.
